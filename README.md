# Data Science Projects

A portfolio of end-to-end data science projects by **Mariama Sanyang**.

## Projects

| Project | Description | Key Result |
|---------|-------------|------------|
| [Credit Card Fraud Detection](credit-card-fraud-detection/README.md) | Classify fraudulent transactions from 284,807 anonymised credit card records; full detection pipeline with threshold tuning and cost analysis | XGBoost test PR-AUC: **0.8687** |
| [SMS Spam Detection](sms-spam-detection/README.md) | Classify SMS messages as spam or ham; TF-IDF + Naive Bayes with preprocessing comparison, threshold tuning, and a predict CLI | Naive Bayes test PR-AUC: **0.9755** |

---

Each project is self-contained with its own environment, data download instructions, and reproducible pipeline.
